# The Little Light — asset provenance

Original fixture created for AETHER Fx on 2026-10-10. The twelve-part character, cubic backgrounds, table, lantern, woven-paper PNG and stereo score were authored specifically for this project by `scripts/create-short.mjs`. They contain no reused illustration or sampled music. The project currently declares ISC; original fixture assets follow that declaration. The owner's final copyright/NOTICE declaration remains a publication prerequisite, as recorded in RELEASE-READINESS.md.

Nunito is third-party font software, not original project artwork. Source: https://github.com/google/fonts/tree/main/ofl/nunito . The exact downloaded variable TTF is stored in assets/Nunito.ttf and its SHA-256 is in manifest.json. Copyright 2014 The Nunito Project Authors (https://github.com/googlefonts/nunito). License: SIL Open Font License 1.1; the complete text is preserved in assets/Nunito-OFL.txt. The font has not been renamed or modified. No system font is used as an implicit substitute.

The PNG is an original 128x128 RGB landscape texture. The score is 20 seconds of 48 kHz stereo 16-bit PCM WAV, synthesized from original sine/pluck notes. It includes distinct 880, 1320 and 1760 Hz synchronization pulses at global frames 24, 168 and 360. A gold visual dash is visible for three corresponding frames; sync-markers.json records sample/frame positions. These pulses are intentional test instrumentation in the acceptance short.

The `.afx` file remains the executable authoring artifact. Its generator rebuilds deterministic geometry, PNG, WAV and manifest; it does not download fonts. All morphs use explicit semantic contour/segment correspondence. The lantern switches to the hand's local origin at frame 204, with a (0,20) offset that keeps the handle under the hand. Front-arm/hand layer keys declare occlusion explicitly. The four poses are idle, reach, lift and smile; drawings switch the eyes for blinks. Background actors have separately declared parallax.
